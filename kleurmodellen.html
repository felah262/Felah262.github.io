Kleurmodellen

Wat zijn kleurmodellen?

Een kleurmodel is een manier waarop kleuren digitaal worden beschreven. Computers kunnen kleuren niet gewoon "zien" zoals mensen dat doen. Daarom worden kleuren opgeslagen als getallen.

Er bestaan verschillende kleurmodellen. Voor computers en digitale schermen is vooral het RGB-kleurmodel belangrijk. Voor drukwerk wordt vaak CMYK gebruikt.

RGB

RGB staat voor Rood (Red), Groen (Green) en Blauw (Blue). Met deze drie kleuren kan een computer heel veel verschillende kleuren maken.

Iedere kleur krijgt een waarde. Bij RGB ligt deze waarde meestal tussen 0 en 255.

Rood: RGB(255, 0, 0)

Groen: RGB(0, 255, 0)

Blauw: RGB(0, 0, 255)

Wit: RGB(255, 255, 255)

Zwart: RGB(0, 0, 0)

Hoe werkt RGB?

Stel dat we de kleur RGB(255, 100, 50) hebben. Dit betekent:

  • Rood heeft een waarde van 255.
  • Groen heeft een waarde van 100.
  • Blauw heeft een waarde van 50.

De computer combineert deze drie waarden en maakt daar één kleur van. Door de waarden te veranderen, kan de computer miljoenen verschillende kleuren maken.

CMYK

CMYK wordt vooral gebruikt voor printen. CMYK staat voor:

  • C = Cyaan
  • M = Magenta
  • Y = Yellow (Geel)
  • K = Key (Zwart)

Bij RGB worden kleuren gemaakt door licht toe te voegen. Bij CMYK wordt juist gewerkt met inkt die licht absorbeert. Daarom is RGB vooral geschikt voor schermen en CMYK vooral geschikt voor drukwerk.

Waarom zijn kleurmodellen belangrijk?

Kleurmodellen zorgen ervoor dat computers kleuren op een vaste manier kunnen opslaan, verwerken en weergeven. Wanneer je bijvoorbeeld een afbeelding op je computer bekijkt, worden de kleuren van die afbeelding opgeslagen als digitale waarden.

Een computer kan daardoor bijvoorbeeld onthouden dat een pixel RGB(255, 0, 0) is. De computer weet dan dat deze pixel volledig rood moet worden weergegeven.

Kort samengevat

  • RGB gebruikt rood, groen en blauw en wordt vooral gebruikt voor schermen.
  • HEX is een compacte manier om RGB-kleuren op websites te noteren.
  • CMYK gebruikt cyaan, magenta, geel en zwart en wordt vooral gebruikt voor drukwerk.
  • Computers slaan kleuren op als getallen.
  • Door verschillende waarden te combineren kunnen heel veel verschillende kleuren worden gemaakt.
